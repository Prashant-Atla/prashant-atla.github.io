# Prashant Atla — personal website

A static website for GitHub Pages. No build or installation is required.

## Preview
Open `index.html` in a browser. The site contains responsive navigation, an interactive engineering workflow, three project stories, a career timeline, education and certifications, email and social links, and a printable résumé.

## Publish the update
Upload `index.html`, `styles.css`, `script.js`, `resume.html`, and `.nojekyll` into the root of `Prashant-Atla/prashant-atla.github.io`, replacing the existing files. Keep GitHub Pages configured to deploy from `main`, `/ (root)`. The website remains at https://prashant-atla.github.io/.

## Content
Career details come from the supplied CV. The current Pulsan Omsorg role was confirmed by the owner. Project diagrams describe areas of work conceptually and do not claim to depict internal company architecture. No performance figures, testimonials, or project outcomes were invented.

The résumé omits the private home address, date of birth, and phone number. It can be saved as PDF through the browser print dialog. Google Fonts provides optional typography; system fonts are used if it is unavailable.

## Validation
JavaScript syntax and local links checked. Browser checks covered desktop and mobile widths, workflow selection, all three project dialogs, and Escape-key dismissal. Publication requires an account with write access to the GitHub repository; the connected account had read-only access when the redesign was prepared.
